Identify 5 different HTML elements
1. <header> - This element is used to define the header section of a webpage, which often contains the site logo, navigation links, and other introductory content.
2. <footer> - This element is used to define the footer section of a webpage, which typically contains copyright information, links to privacy policies, and contact details.
3. <section> - This element is used to define a section of content within a webpage, often used to group related content together.
4. <article> - This element is used to define an independent piece of content, such as a blog post or news article, that can stand alone.
5. <aside> - This element is used to define content that is tangentially related to the main content, such as sidebars, pull quotes, or advertisements.
